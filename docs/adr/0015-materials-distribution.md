# 0015: 实操素材包分发——网盘 + 应用内导入

日期：2026-10-11 · 状态：已采纳

## 背景

40 题实操素材（考卷 ipynb + 数据 + ONNX 模型）约 220MB。早期版本要求用户手动把素材包
解压到固定目录并在应用里指认——实测踩坑不断：默认目录与素材包真实布局不符、旧版误建的
空壳文件夹被选中、explorer 对正斜杠路径静默回落到「文档」目录。曾考虑把素材打进安装包
（bundle.resources + CI 从 GitHub Release 拉取），但安装包会膨胀到 200MB+，且构建链依赖
不稳的 GitHub 大文件下载。

## 决策

- **素材 zip 走百度网盘分发**（用户上传桌面打包的 UTF-8 zip），不进安装包、不进 git；
- **应用内一键导入**：环境助手「实操素材包」卡片与实操页缺素材提示均提供「导入素材包」
  ——选 zip → `import_materials`（zip crate 流式解压）：zip-slip 防护、自动剥离单层父
  目录、校验 ≥30 个题号文件夹（应为 40）、临时目录解压后整体换入（被 Jupyter 占用时
  明确报错提示先停止）、写 `.imported` 标记；
- 导入成功落库 `materialDir` 并置 `materialDirCustom`；App 启动钩子对未显式指认过的用户
  自动迁移默认目录到应用素材目录（ASCII 路径，见 ADR-0014 的 app_data_root）；
- 保留「更换素材总目录」指认已解压文件夹的路径作为备选。

## 后果

- 安装包保持小巧；素材更新只重传 zip + 重新导入，与应用发版解耦；
- 中文 Windows 用户「重新压缩 zip」会产生 GBK 文件名——导入校验会明确拒绝；务必分发
  Mac 打包的 UTF-8 zip（ditto -c -k）；
- 重新导入会覆盖素材目录（含做题写进素材夹的产物），UI 文案已警告。
